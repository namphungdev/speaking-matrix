## Frameworks & runtimes

- **dotnet** (`services/api/SpeakingMatrix/*/*.csproj`): .NET 10 (`net10.0`,
  `Nullable` + `ImplicitUsings` enabled), ASP.NET Core Web API, solution file
  `SpeakingMatrix.slnx`. Libraries: Microsoft.AspNetCore.Authentication.JwtBearer
  10.0.14, Microsoft.AspNetCore.OpenApi 10.0.13, Swashbuckle.AspNetCore 10.3.1,
  Newtonsoft.Json 13.0.4 (Api); Microsoft.EntityFrameworkCore.SqlServer /
  .Design 10.0.14, Microsoft.AspNetCore.Identity.EntityFrameworkCore 10.0.14
  (Infrastructure). Local tools in `dotnet-tools.json`.
- **react-js** (`apps/web/package.json`): React 18.3 + ReactDOM, Vite 5.4
  (`@vitejs/plugin-react`), Tailwind CSS 3.4 + PostCSS/Autoprefixer, plain
  JavaScript/JSX (no TypeScript, no ESLint, no test runner). Web Speech API;
  FontAwesome 6 and Google Fonts from CDN (`index.html`).

## Toolchain error taxonomy

**msbuild (dotnet)**

| Code | Meaning | Typical fix |
|---|---|---|
| CS0246 | Type/namespace not found | Add `using` or the missing `ProjectReference`/package |
| CS0234 | Namespace member missing | Wrong namespace — check `SpeakingMatrix.<Layer>.<Folder>` |
| CS8618 / CS8602 | Nullable warnings (Nullable enabled) | Initialize/`required`, or null-check — don't `!` |
| CS0103 | Name does not exist in context | Missing variable/using; typo |
| NU1101 / NU1102 | Package/version not found | Fix package id or use a version available for net10.0 |
| NETSDK1045 | SDK does not support net10.0 | Install .NET 10 SDK |

**Vite / Rollup (react-js)**

| Error | Meaning | Typical fix |
|---|---|---|
| `Failed to resolve import "./x"` | Wrong relative path or missing file | Fix path/extension (`.jsx`) |
| `"X" is not exported by "..."` | Named vs default export mismatch | Components are default exports; data modules use named exports |
| `Unexpected token` / `Expected ...` (esbuild) | JSX/JS syntax error | Fix the syntax at the reported line |
| PostCSS `The \`x\` class does not exist` | `@apply` of an unknown class | Define it in `tailwind.config.js` or `src/index.css` |

## Environment notes

- .NET 10 SDK required. The API needs `ConnectionStrings:DefaultConnection`
  and `Jwt:Issuer`, `Jwt:Audience`, `Jwt:SigningKey` (base64, ≥32 bytes) —
  set via user-secrets (`UserSecretsId` on the Api project) or env vars; it
  throws at startup without them. SQL Server is required to run, not to build.
- Node + npm for `apps/web`; run commands from `apps/web`.
