- [ ] Each file adds component-specific information.
- [ ] Local commands and technology details are verified.

## Accuracy and Maintainability

- [ ] No contradictory commands or rules remain.
- [ ] Relative links and paths were checked where possible.
- [ ] Existing useful instructions were preserved.
- [ ] Automated enforcement opportunities were identified.
- [ ] Validation results distinguish inspection from executed checks.

## Completion Report
- [ ] Created and modified files are listed.
- [ ] Evidence sources are summarized.
- [ ] Actual validation results are reported.
- [ ] Unresolved questions and risks are stated.
